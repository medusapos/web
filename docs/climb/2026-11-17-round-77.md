## Checked against the source

- **The badge says app 0.2.0, and the hero caption says the demo runs the
  latest build (visitor, sceptic, owner, developer): both are true.** The
  badge reads `siteConfig.release`, which a test ties to the changelog and
  the latest GitHub release of medusapos/app (v0.2.0). The demo serves
  main. Naming the hosted build would need its build identifier, which is a
  new claim with no source on the site.
- **The desktop hero cart rows sit about 85 px apart (visitor, sceptic,
  owner): true.** That is the demo's own row height, cropped at 2x. Tighter
  rows would need a new capture of a different screen, or edited pixels,
  and the site doesn't edit app screenshots.
- **The first phone screen is all text, with the till at the bottom edge
  (owner, phone 8): true.** After #299, Live demo ends at 434 px instead of
  574 px. The till shot follows the fine print below `lg`, as chosen in
  earlier rounds.
- **The `medusa-config.ts` chip in the quick start breaks at its hyphen on a
  phone (designer, phone 8): true.** It is the browser's line break in
  inline code. A test keeps short hyphenated names whole in code blocks,
  but nothing does the same for inline chips.
