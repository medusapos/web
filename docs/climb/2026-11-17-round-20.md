## Checked against the source

- **The fees section never names a control (visitor, docs 8): true.**
  medusapos/app@c027779 `apps/expo/components/cart-add-menu.tsx` line 19 has
  a **+** menu with Add Fee, Add Shipping and Add Miscellaneous Product.
  v0.2.0's `e2e/charges.spec.ts` uses **Add charge** and then Fee, Shipping or
  Custom item. Spec GG.
- **No page says whether another Medusa version works (sceptic, docs 7):
  true.** `npm view @medusapos/medusa-plugin@0.2.3 peerDependencies` names
  `2.21.0` exactly for `@medusajs/medusa` and `@medusajs/framework`. Spec HH.
- **"Covered by the app's automated tests" has no link (visitor and designer,
  trust 8; designer in round 18): true.** medusapos/app@c027779
  `.github/workflows/ci.yml` runs unit and browser tests on every pull request
  and push to main. Spec II.
- **One register per store is buried (sceptic): partly.** It is already the
  last item of "Not there yet" and in the Phone and counter card. Not changed.
- **Footer links are small on phones (owner): false.** Each footer link
  already has `py-3` below `sm`, which makes a 44 px target.
- **Code blocks wrap mid-word on phones (sceptic): true, kept.** Wrapping is
  the round 3 choice (#53).
