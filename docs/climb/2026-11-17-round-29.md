## Checked against the source

- **Printing gets one clause (owner docs 7, sceptic and visitor docs 8):
  true.** At medusapos/app main `69f6f81`, `apps/expo/app/settings.tsx`
  lines 225-240 have Settings › Printing: the print dialog, and "Automatically
  print receipt after checkout", saved on this till only.
  `lib/printing-settings.ts` has it off by default, and
  `e2e/order-receipt.spec.ts` prints only the receipt. Spec NN. No printer,
  paper width or cash drawer is named, because nothing in the source tests
  one.
- **The RBAC setup has no heading (developer clarity 8, designer docs 8):
  true.** It was step 7 of Configure your store, with three nested steps.
  The quick start also repeated the locking text that Plugin setup now
  covers. Spec MM.

  front desk, with the version eyebrow.

- **The footer tap size** (designer and visitor phone 8): round 28 measured
  `py-3` below `sm`, about 44 px, so this does not hold.
