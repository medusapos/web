# Climb round 1, 17 Nov 2026

Paul, 17 Nov 2026: "do a hill climb and judging panel on the API, on the
websites, on the docs etc. ... I want you to maximise it". This repo's part
is medusapos.com, the home page and the docs. The API is medusapos/app and
needs its own worker.

## How the round ran

- Capture: on the live site, 10 pages (the sitemap plus a 404), each at
  1440×900 desktop and 390×844 phone. For each page and width: a fold shot,
  a full-page shot, the page text and metrics (LCP, load, overflow, broken
  images, console errors). The fold shots and `metrics.json` are in
  [`2026-11-17-round-1/`](2026-11-17-round-1/).
- Panel: five judges, each one a separate session with the same brief
  ([JUDGE-BRIEF.md](JUDGE-BRIEF.md)) and its own persona
  ([personas.json](personas.json)). Visitor, owner, designer and sceptic
  ran on Opus 5.5 (pool one-shots). Developer ran on Codex GPT-6 Astra,
  read-only.
- Each judge scores seven criteria from 1 to 10 and names the single worst
  defect for each one.

Codex wrote #46 and #47 from written specs. An Opus pool implementer took
the screenshots for #45 and handed the `page.tsx` change to Codex. The
reviewing session read each diff against its spec. All three merged on
green CI.

Not shipped:
- **New desktop hero image.** The demo store runs a build newer than 0.2.0.
  Its desktop cart shows a Checkout button, order notes and sale tabs, none
  of which are in 0.2.0, so shipping that image would claim features the
  release lacks. Proposed to the front desk.
- **The 0.1.0 sync figure on Limitations** (sceptic, correctness 6, kind
  `new-claim`). It needs a measured 0.2.0 figure, which is a product claim,
  so it is proposed to the front desk and not shipped.

## Open defects for later rounds

- Home "Live demo and release 0.2.0" table: 11 rows of Yes/Yes repeating the
  cards above it (all five judges, 7 or 8).
- Phone code blocks run under the copy button; inline `medusa-config.ts`
  breaks at its hyphen (designer, phone 7).
- Plugin setup options table is cramped at 390 px (developer phone 7,
  visitor phone 8).
- Troubleshooting says "the till opens offline too" right before saying a
  reload offline fails (developer, correctness 7).
- Quick start step 3 leaves out the shipping-profile requirement
  (developer, docs 8).
- Plugin 0.2.3 versus release 0.2.0 is explained only in the changelog
  (designer, correctness 7).
- Brand accent: the app's indigo appears only in the screenshots (designer).
  This is a design change, so it is proposed rather than shipped.
