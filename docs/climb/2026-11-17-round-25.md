## Checked against the source

- **The phone section sits off the content edges (designer visual 7, owner
  visual 7): true.** #134 centred it in a `max-w-4xl` box, so at 1440 px the
  shot started at x≈272, while every other section starts at 168. Spec XX.
- **The Redis locking example is two packed lines that never say to set
  `LOCKING_REDIS_URL` (developer visual 8 and docs 8, sceptic phone 8):
  true.** Spec WW.
- **The quick start's Make a sale leaves out Take (visitor correctness 8):
  true.** At the till, sourced from the app's e2e helpers, has Exact or the
  amount, then Take, and for a card the terminal's reference. Spec YY.
- **The changelog's RBAC line omits super admins (developer correctness 8):
  true but historical.** The 0.2.0 entry records what that release said.
  Quick start and Limitations already state that super admins keep access.
  It is a candidate for a note beside the entry.
- **The hero shot shows "Add order note" while the page says notes don't
  reach the order with plugin 0.2.3 (sceptic correctness 7): true.** Both
  are accurate: the hosted app shows the box, and Not there yet says the
  note is lost. Recropping or recaptioning the hero is the hero proposal
  already with the front desk.
