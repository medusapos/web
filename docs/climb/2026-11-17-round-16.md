## Fixed forward, not reverted

Most of the drop traces to #99, the hosted-build copy:
- Its intro under "What it does today" carries three version ideas in one
  sentence (owner, visitor, sceptic).
- The home page shows "Add order note" but never says the note doesn't reach
  a 0.2.3 store. Only Limitations does (owner, visitor, sceptic, designer).
- Saying that the hosted app runs the latest build exposed a gap: the docs
  still taught release 0.2.0's cart buttons.

Reverting #99 would put back "the version you install today", which the front
desk's ruling A removed because it was untrue. So this round fixes the
wording forward and keeps the ruling's facts.
