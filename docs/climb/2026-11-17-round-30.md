  true.** After #153 the card said, in one breath, that approval is needed
  and that any login can give it. Spec OO.
- **No sales region in Configure your store (sceptic docs 7, developer docs
  8): true.** At medusapos/app@bc4570a, `docs/testers.md` (Set up this

  stock location's country. The app's own quick start doesn't set one up
  either. Spec PP. The sceptic also asked for inventory levels. Nothing in
  the source says what the till does without one, so the docs say nothing
  about them.
- **Two wordings for the payment screen (visitor correctness 8, owner
  correctness 9): true.** Spec QQ.
- **"The docs have no screenshots at all" (visitor docs 7): false.**
  Registers and At the till have app screenshots, as the owner's own
  defect shows. The quick start has none (designer docs 8).
- **"v 0.2.0" in the changelog has a stray space (designer correctness 9):
  not checked.** It is set in bold, as a label the app shows. It is a
  candidate until the app source confirms the label.
