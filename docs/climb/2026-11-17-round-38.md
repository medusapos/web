  true.** `lib/layout.shared.tsx` gave the Docs link Fumadocs' default

  current page. Spec MM sets `active: 'none'`.

  (designer phone 8): true.** It is Fumadocs' reading-progress ring

  it; the bar still names the section and opens the list.

  7): true.** Spec OO adds one shot of the sign-in form from
  app.medusapos.com (`medusapos/app` main `ba317a1`), with the example
