## Checked against the source

- **At the till is the slowest docs page (four judges, speed 9): true.**
  Its LCP element is the payment screenshot, which loaded lazily. Measured on
  production over five loads at 1440 px, it took 408–512 ms, against about
  300 ms for pages whose LCP is text. Spec F54 preloads that one image. After
  it deployed, round 55 measured At the till's LCP at 296–316 ms.
- **Quick start doesn't show the Open register panel (designer, docs 8):
  true.** Step 1 showed only the header control. Spec G54 adds a capture of
  the panel from the live demo with a float typed in. Open register was not
  pressed.
- **The receipt example reads like wrong arithmetic (designer, correctness
  8): true.** The amounts were left-aligned and the total looked like any
  other row. Spec H54 right-aligns the amounts and bolds the total.
- **The home footer links are about 20 px tall (designer, phone 8):
  false.** Each link is 44 px tall at 390 px on production.
- **Quick start needs a "Jump to" row on a phone (owner, phone 8): already
  there.** Fumadocs shows an "On this page" menu at the top of every docs
  page on a phone.
