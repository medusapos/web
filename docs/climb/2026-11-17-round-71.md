## Checked against the source

- **The changelog's 0.2.0 limits say "No order note", while the other pages
  describe an Order note box (owner, correctness 9; sceptic, clarity 8):
  true, but not a contradiction.** Release 0.2.0 has no box, and the
  changelog's site note says the hosted build added one. Spec A72 says which
  build is which in that line.
- **At 390 px, `npm install @medusapos/medusa-plugin@0.2.3` breaks at
  `medusa-` (designer, phone 8): true.** The browser breaks at the hyphen.
  Spec B72 keeps a short hyphenated name on one row, so the line breaks
  after `@medusapos/`, the break point round 46 set.
- **On a phone, the demo note and the Sign in line come after the hero
  screenshot (visitor, phone 8; owner, clarity 8): true, and on purpose.**
  Round 56 (#260) moved them there so that a phone's first screen shows the
  till. That is kept.
- **The register control screenshot doesn't show where the control sits
  (designer, docs 8): true.** A crop of the whole header would be too small
  to read on a phone, so it is left for a better capture.
- **"Not there yet" sits in a side column (designer, trust 8): not done.**
  Round 43 (#212) put it there on purpose.
- **The "Sells offline" card doesn't give the 50-sale batch limit (sceptic,
  trust 7): not done.** The limit is in "Not there yet" on the same page.
  Putting it in the card would say how a queue becomes a batch, and no
  source settles that.
- **"Also at the till" is long on a phone (owner, visual 8; sceptic, phone
  8): true.** Since #285 each row carries its caveats. A shorter form would
  drop them again, so it waits for a layout that keeps them.
- **The hero screenshot is unreadable, the lede is long, the versions are
  unlabelled, and the pay screen differs from release 0.2.0 (designer,
  developer, sceptic and visitor): true.** These are with the front desk.
