## Checked against the source

- **The docs screenshots have no common scale (designer visual 7): true.**
  Every shot was stretched to the full 804 px column, whatever its pixel
  size. Spec EEE shows each one at half its pixel width, the app's own size.
- **The Introduction asks for "a Medusa 2.21.0 store" while every other page
  says "exactly" (visitor correctness 8): true.** Spec FFF says "exactly",
  linking to the reason on Limitations.
- **The Sells offline card promises sync without the batch limit (developer
  trust 8): true.** Spec GGG added the limit to the card. Round 45 found the
  longer card worse, as above.
- **The Registers page's desktop LCP of 2452 ms (developer, owner, sceptic
  and visitor speed 8): a one-off.** Three fresh loads measured 352, 356 and
  420 ms. The capture script now reports the median of three loads for every
  view.
- **Code blocks wrap inside words on a phone (owner and sceptic phone 8):
  true, kept.** The wrap is deliberate, so a command reads without sideways
  scrolling.
- **The hero shows "Add order note" (visitor trust 8): true, kept.** The hero
  is a capture of the hosted app, which has the button, and Not there yet
  says the note doesn't reach the order with plugin 0.2.3.
