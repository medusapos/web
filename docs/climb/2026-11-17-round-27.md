## Checked against the source

- **The hero screenshot can't be read (designer, owner and sceptic, visual
  7): true.** It was a 1216 x 1106 capture shown about 620 px wide, so its
  text came out at half size. Spec DD recaptured the live demo's sale screen
  at a 1000 x 680 window, device scale 2, with the same cart and total. Its
  text is now drawn at 62% of size, up from 51%.
- **At the till's Fees section names no control (designer docs 8): true, and
  the page was also wrong about the order discount.** On the live demo, the
  cart has no "Order discount" control below the lines. The order discount,
  fees, shipping and one-off items are all in the cart's **+** menu
  (`apps/expo/components/cart-add-menu.tsx:32-37` at medusapos/app
  `5fc5b95`). Spec EE fixes both sections.
- **The footer's Help link opens Report a problem (owner correctness 8):
  true.** It pointed at `#report-a-problem`. Spec FF points it at the top of
  Troubleshooting.
