## Checked against the source

- **Nothing about the 50-sale batch limit (owner docs 7): true.**
  The medusapos/app v0.2.0 notes ("Oversized batches get a clear answer") and
  app#134 (`MAX_COMMANDS = 50`) say the store refuses a larger batch whole.
  The till can't split it yet. Spec DD puts it in Limitations, Troubleshooting
  and the home page's Not there yet.
- **"Move the store to 2.21.0 first" with no how-to (visitor docs 7): true.**
  Medusa's own [Updating Medusa](https://docs.medusajs.com/learn/update)
  guide gives the steps: bump the `@medusajs/*` packages, reinstall, then run
  `npx medusa db:migrate`. It covers moving up only. Spec EE links it from
  both places, for moving up only.
- **The Sells offline card has no caveat (owner trust 8): true.** Limitations
  already says reloading while offline fails, but the card didn't. Spec FF
  adds the caveat to the card, with no new claim.
