## Most-named defect: a held sale had no next step

Four judges (sceptic, visitor, developer and owner) hit the same dead end.
Troubleshooting said some sales "have no Retry" and stopped. Plugin setup said
the admin clears them "with one command" but never named it. The plugin
documents that command, and the log line that names the sale, in its README and
source, so documenting them adds no new claim. Spec Y does that.
