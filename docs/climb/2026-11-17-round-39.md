## Checked against the source

- **"Medusa 2.21.0 exactly" gives no way to check a store's version (visitor
  clarity 8): true.** The quick start's What you need already has the check
  (`npm ls @medusajs/medusa`). Spec PP links the words there.
- **Wrapped code lines restart at the block's left edge on a phone (designer
  phone 8): true.** In Plugin setup, the nested `locking-redis` config wraps
  to column 0, so a continuation reads as a new, shallower line. Spec QQ adds
  a hanging indent. Its first version replaced Fumadocs' 16 px line padding
  instead of adding to it, which moved every first row and split two
  commands at a hyphen; QQ2 fixed that before review. The row breaks now
  match production at 390 px.
- **The browser band shows a phone beside desktop copy, unexplained
  (designer visual 7): true.** Spec RR shrank the image to 240 px, which would
  undo round 24's #134 (220 px read as a sliver), so it was dropped. RR2 keeps
  320 px and adds the caption "The same app on a phone".
- **Footer links are small tap targets (designer phone): false.** They
  measure 44 px tall at 390 px, as in round 38.
