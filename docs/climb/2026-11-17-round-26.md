## Checked against the source

- **The docs have no screenshots (designer visual 7, sceptic visual 7,
  owner visual 8): true.** No docs page had an image. Spec CC adds the
  payment screen, the count and the closure (Z report), captured from the
  live demo.
- **Registers' "the open card is filled in with the cash you just counted"
  (designer docs 8): wrong, not only unclear.** On the live demo, after
  **Done** the Open register amount field is empty, and the panel offers
  **Use the last counted cash (€100.00)**. Spec CC names that button.
- **No page says how staff get their own logins (owner docs 7): true.**
  Spec AA gives Medusa Admin's own invite flow, quoted from Medusa's user
  guide.
- **No page says how to check the store's Medusa version (visitor docs 7):
  true.** Spec BB adds `npm ls @medusajs/medusa`, and what to do on another
  version, from Limitations. The visitor's "if newer, wait rather than
  downgrade" would be a new support claim, so it is not added.
- **"Medusa … has no tax classes" (sceptic correctness 8): needs a source.**
  Whether the limit is Medusa's or the plugin's has to be checked against
  the app and plugin source before the wording changes, so it is a
  candidate, not a change.
