## Checked against the source

- **The home grid and the Introduction leave out fees and one-off items
  (visitor correctness 8, sceptic correctness 9): true.** At the till and
  the 0.2.0 changelog list them. At medusapos/app@562fcba,
  `apps/expo/tests/cart-add-menu.test.tsx` and the plugin's
  `order-create-v5.spec.ts` ("a taxable bag fee ... with the fee as a
  variant-less item") cover them. Spec RR.
- **Registers never mentions Print the Z report (owner docs 8): true.**
  At medusapos/app@562fcba, `register-close.tsx:212` shows the button, and
  `closure-print.ts` `printHtml` opens the browser's print dialog from a
  hidden iframe. Spec SS.
- **The hero fine print is crowded (designer clarity 8, visitor clarity 8):
  true.** Spec TT. Its first version dropped "The demo store resets every
  night." because the page repeats it beside a later demo link. The review's
  browser check found that line sits in a section that renders only while a
  feature is unreleased, so the hero is the only place it shows. The amended
  spec TT2 keeps the sentence and joins the two plugin sentences.
- **Put the approval caveat back on the Registers card (sceptic trust 7):
  not done.** #157 moved it to Not there yet a round ago because the card
  undercut itself (sceptic trust 7 then). Moving it back would oscillate.
- **"Where do you open and close the register?" (visitor docs 8): false.**
  The quick start's Make a sale links to `/docs/registers#open-with-your-float`
  and `#count-and-close`.
- **Code blocks wrap mid-token at phone width (designer phone 8): a
  deliberate choice.** `app/global.css` sets `pre-wrap` and
  `overflow-wrap: anywhere` on Shiki blocks so a long command never
  scrolls the page sideways.
