## Checked against the source

- **Docs screenshots don't match the home page's frame (designer, visual
  7): true.** The home page frames screenshots with rounded corners and a
  shadow; the docs used square corners and a plain border. Spec L55 gives
  the docs the same frame. Widths, zoom and the phone "Tap to enlarge" line
  are unchanged.
- **Quick start sets up shared locking "first" after the migration
  (developer, docs 9): true.** The paragraph came after the migration
  command it says to come before. Spec J55 moves it, unchanged, ahead of
  that step.
- **"Counter or phone" reads as two pieces on a phone (owner, phone 9):
  true, not taken.** Joining its two sentences gives about 138 characters.
  A round 52 test caps each phone row's first sentence at 110 (#245), and
  a round 46 test pins the card's limit-first wording (#223). The spec
  stopped without a change.
- **The footer links are about 20 px tall (sceptic, visitor): false.** Each
  is 44 px tall at 390 px on production.
- **The changelog says "Medusa POS" (designer): false.** The page has no
  such string.
- **Code blocks wrap on a phone (designer): by design.** They wrap with a
  hanging indent instead of scrolling sideways.
- **Number the Quick start headings (designer, docs 8): not taken.** It
  would rename headings that 16 test slices and the docs' links use as
  anchors.
- **Say how to set up a separate POS sales channel (visitor, docs 8): not
  taken.** It needs facts about the channel's products that no source on
  the site gives.
