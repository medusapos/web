## Checked against the source

- **Docs prose links have a heavier underline than the home page's (designer,
  visual 7): true.** Measured on the live site: docs links have a 1.5 px
  near-black underline 3.5 px below the text; home links use the text colour
  at the browser's default thickness. Spec A66 gives docs links a 1 px
  underline at half the text colour. The indigo hover the judge suggested is
  the brand colour layer, which is with the front desk.
- **An empty band sits between the hero and "What it does today" (designer,
  phone 8; visitor, visual 8): true.** It measures 128 px at 1440 px and
  96 px at 390 px: the hero's bottom padding adds to the next section's top
  padding. Spec B66 trims the hero's bottom padding.
- **"Each tender's counted, expected and difference" doesn't read as a list
  (designer, correctness 9): true.** It appears in the quick start and in
  Registers. Spec C66 names the amounts.
- **The home header's menu button is a bare chevron (visitor, phone 9):
  true, and left for now.** It already has the label "Toggle Menu" for screen
  readers; the icon is the docs theme's.
- **The docs Introduction repeats the home feature list (visitor, docs 8):
  true, and left for now.** The Introduction is the page a backend person is
  sent to, and it has to stand on its own.
- **The hero screenshot shows "Add order note" (designer and visitor):
  true.** It goes with the hero recapture, whose size and crop are with the
  front desk.
- **On a phone, the hero's demo and Sign in notes sit below the screenshot
  (designer, phone 8): true, and left as is** (round 56, #260).
